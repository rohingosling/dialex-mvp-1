# Dialex solar installer prototype

Open **Open Dialex.cmd**, or open **index.html** in your browser. No installation or internet connection is required.

Harbour Solar is a fictional Sydney solar installer. The prototype includes the overview, voice-agent configuration, guided setup, a simulated agent test, searchable call history and usage/pricing screens. Changes remain in the current tab until you reload.

For a demonstration, open Voice agents, choose Harper, select Test agent and run the sample conversation. Open Call history to explore quote enquiries, site visits, battery callbacks, requests for a human, installation-process questions and an off-grid enquiry. Search for a name, suburb or topic such as off-grid. Create agent opens a new draft with guided setup.

All businesses, people, calls and bookings are fictional. Daniel demonstrates a successful booking with a connected calendar. Olivia demonstrates a visit request awaiting staff confirmation. No live calendar integration is connected. The prototype does not authenticate, make calls, use a microphone, send messages, create appointments or collect payments. The sample conversation demonstrates a fixed pattern rather than running the configured instructions through an AI service. Outbound and support agents are proposed concepts, not launch commitments.

All prices are illustrative Australian dollars, excluding GST. They are discussion assumptions, not published prices or supplier quotes.

If you prefer a local web address, run `node server.mjs` from this folder and visit [Dialex on this computer](http://127.0.0.1:4173). The server exposes only the prototype assets on the loopback address.

Design reference: [Microsoft Fluent 2 shapes](https://fluent2.microsoft.design/shapes), [colour](https://fluent2.microsoft.design/color) and [materials](https://fluent2.microsoft.design/material). The prototype uses a custom Fluent-inspired treatment with Segoe UI, dark surfaces, shared spacing, blue actions and yellow accents.
